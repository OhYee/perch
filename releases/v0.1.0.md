# v0.1.0

初始版本提供本地 `agent-session` CLI，用于发现和管理当前用户的 OMP、Codex CLI 和 Claude Code 会话，无需常驻中心服务。

- 支持会话列表、历史和消息投递，以及托管会话的启动、等待和关闭；OMP 托管会话支持恢复。
- 支持可选 OMP 扩展、原生 OMP 终端输入，以及通过 `terminal-pane` 展示或启动会话。
- 提供中英文提示和适合脚本使用的 JSON 输出。

需要 Node.js 22.13 或更高版本及对应提供方；pane 功能另需 `terminal-pane`。本机发现与发送在 macOS 上验证，新增的 Claude 托管路径尚未实机验证。提供方能力和其他限制见 [README](../README.md)，贡献及安全报告分别见 [CONTRIBUTING.md](../CONTRIBUTING.md) 和 [SECURITY.md](../SECURITY.md)，AI 维护及发行流程见 [AGENTS.md](../AGENTS.md)。
