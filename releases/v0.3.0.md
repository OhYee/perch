# v0.3.0

Perch 新增 Google Antigravity CLI（`agy`）支持。使用前请安装并登录 `agy`。

- **托管会话**：`perch start agy` 通过 ACP 新建会话，支持 `send`、`wait`、`history`、`view` 和 `close`。`resume` 只恢复由 Perch 创建、且能由 agy 加载的对话；恢复时沿用原 ID，不会重发消息。Perch 不会代批权限请求。
- **原生终端**：`perch start agy --native --pane right` 打开交互式终端，`perch list --provider agy` 列出可识别的进程。macOS 上的 agy 1.5.16 可手动配置状态行以识别当前对话；查询期间没有可验证的报告时，只显示进程线索。原生对话不支持读取历史、发送消息、注入按键、等待或关闭，请在原终端操作。

下载所需的发行文件及同一版本的 `SHA256SUMS.txt`，校验后再运行。
