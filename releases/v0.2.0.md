# v0.2.0

v0.2.0 是 Perch 的首个正式版。此前使用同版本线 Beta 的用户可运行 `perch update --check` 查看更新，再用 `perch update` 安装正式版。

- 使用 `perch --version`、`perch -V` 或 `perch version` 查看当前版本；`perch version --json` 提供机器可读输出。
- 使用 `perch update --check` 检查更新；需要检查 beta 时可指定 `--beta`。`perch update` 可更新受支持的发行安装，并使用发行校验文件验证下载资产。没有可信发行来源的本地安装需通过 `--repo OWNER/REPO` 显式指定仓库。
- 源码检出不会被发行资产覆盖。独立二进制、单文件 JS 和 npm tarball 的安装方式见 [安装指南](https://github.com/OhYee/perch/blob/v0.2.0/README.md#安装与要求)。

下载本页所需文件及 `SHA256SUMS.txt`，校验后再运行。Linux 独立二进制需要 glibc；单文件 JS 和 npm 包需要 Node.js 22.13 或更高版本。
