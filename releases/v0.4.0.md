# v0.4.0

Perch 默认以非交互全权限模式启动托管会话，并在 OMP 集成扩展中新增原生 `perch` 工具与异步回推能力。

- **托管会话默认 full-access / yolo**：`perch start` 启动的托管后端默认跳过交互权限弹窗，适用于自动化后台执行（仅在可信工作目录中使用）：
  - `agy`：`agy acp --dangerously-skip-permissions`
  - `codex`：`thread/start` 传入 `approvalPolicy: "never"` 与 `sandbox: "danger-full-access"`
  - `omp`：`omp --mode rpc --approval-mode yolo`
  - `claude`：`--permission-mode bypassPermissions --dangerously-skip-permissions`
- **OMP 集成扩展内置 `perch` 工具**：通过 `perch integration install omp` 加载后，OMP 会注册 `perch` 工具并在 `/vibe` 模式下自动加入可用工具列表，支持 `list`、`start`（可附带 `prompt` 一步启动并派发）、`send`、`wait`、`history`、`resume` 和 `close`。
- **异步完成回推与自动清理**：`perch` 工具在 `start(prompt)` / `send` 时默认开启 `notify: true`，在后台非阻塞等待轮次结束后以 follow-up 消息自动唤醒当前 OMP 会话并附带最新回复摘要；切换会话时自动取消旧监听，退出会话时自动关闭本会话派生的托管进程。

下载所需的发行文件及同一版本的 `SHA256SUMS.txt`，校验后再运行。
