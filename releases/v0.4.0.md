# v0.4.0

Perch 默认以非交互全权限模式启动托管会话，并在 OMP 集成扩展中新增原生 `perch` 工具、防丢单任务账本、定时心跳与异步回推能力。

- **托管会话默认 full-access / yolo**：`perch start` 启动的托管后端默认跳过交互权限弹窗，适用于自动化后台执行（仅在可信工作目录中使用）：
  - `agy`：`agy acp --dangerously-skip-permissions`
  - `codex`：`thread/start` 传入 `approvalPolicy: "never"` 与 `sandbox: "danger-full-access"`
  - `omp`：`omp --mode rpc --approval-mode yolo`（并注入 `PERCH_MANAGED_WORKER=1`，托管子进程默认隐藏 `perch` 工具防止递归委派）
  - `claude`：`--permission-mode bypassPermissions --dangerously-skip-permissions`
- **OMP 集成扩展内置 `perch` 工具**：通过 `perch integration install omp` 加载后，OMP 会注册 `perch` 工具并在 `/vibe` 模式下自动加入可用工具列表，支持 `list`（`owned: true` 仅看本会话派生任务）、`start`（支持 `name` 标签与 `prompt` 一步启动并派发）、`send`、`wait`、`history`、`resume` 和 `close`。
- **异步回推、定时心跳与防丢单账本**：`start(prompt)` / `send` 默认开启 `notify: true` 与长任务定时心跳（默认 180 秒），后台等待完成后以 follow-up 唤醒当前 OMP 会话；每轮上下文自动注入在途及未处理完成的任务账本，防止长对话或上下文压缩漏单；切换会话取消旧监听，退出会话自动关闭本会话派生的托管进程。
- **原生 `agy` 插件集成与 Herdr 窗格输入**：新增 `perch integration install agy` 与 `perch integration agy-hook`，通过 `agy` 原生生命周期插件（`SessionStart` / `PreInvocation` / `Stop`）持续追踪原生 TUI 对话、解析 `transcript.jsonl` 历史与支持 `wait`；终端输入通道新增 Herdr 窗格前台校验与输入支持（`tmux` / `tern` / `herdr`），并为插件接入的原生 `agy` 会话支持 `input` 与 `send`（多行/长消息自动写入私有临时文件后注入单行引用指令）。
